# Website · Projekt 1024

Dieser Satz ist eine Lüge! Realität oder Illusion? Ein Projekt die das unsichtbare vorstellbar macht...

## So kommt die Seite auf Strato
1. Oben auf **Code → Download ZIP** klicken.
2. Die ZIP-Datei entpacken.
3. FileZilla öffnen und mit dem Strato-SFTP-Zugang verbinden.
4. Die sechs Ordner (Projekt 1024, Endless on Fire, M.A.N.T.I.S. 1024, Das Manifest, Illusion oder Realität, Rising Light - Falling Light) in das Verzeichnis **/Homepage** ziehen. Vorhandene Dateien überschreiben lassen.

Wichtig: Die Formulare brauchen die Postfächer **kontakt@projekt1024.net** und **info@endlessonfire.de** bei Strato. Alle Seiten stehen noch auf `noindex` (Vorschau). Details in **LIESMICH.md**.
